## Context

Operators of an enterprise fiber network platform needed different views of the same data.

## What I did

- Built user-customizable drag-and-drop dashboards on GridStack.
- Shipped 10+ widget types.
- Synced each user's layout to the backend.

## Result

Each user arranges their own dashboard from a shared set of widgets, and the layout follows them across sessions.
